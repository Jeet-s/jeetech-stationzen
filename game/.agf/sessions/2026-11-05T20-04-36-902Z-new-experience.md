Stage 2 is finished and all the required checks pass. I tried the screens in a web preview, not on a phone, so the device QA run is the first real-device test.

**Checks**
- `npx tsc --noEmit`: 0 errors.
- `npm run pitfalls`: 0 errors, 0 warnings.
- `npm run validate`: all 120 levels solvable.
- New `scripts/check-hints.ts`: plays all 120 levels through the screen's own hint layer, the same path QA level replay takes, and wins every one.
- In the web preview, QA-style replay won levels 1, 59, 78 and 85 end to end. Between them they cover drawing lines, extending, loops, the weekly card, dragging a carriage and dragging an interchange.
- Levels weren't changed, so I didn't rerun playtest or the level review.

**What I built**
- **Home (title screen):** follows the target art. Sky over the city map, the logo with a floating motion, Pip the cat on his diorama gently bobbing with glyph tokens drifting around him, star and Token counters, city progress, a big "Play · Level N" button, and round Levels / Shop / Settings buttons.
- **Game screen:**
  - **Map and drawing:** the city background tinted per city; drag between stations to draw a line, or drag a line's end knob to extend it or close a loop.
  - **Trains and stations:** trains sit still while you plan and glide along the lines when a week runs. Stations show what their riders want, how many are waiting, and their overcrowd rings (yellow → amber → Last Call). Tapping a station opens its demand card and highlights the lines its riders take, which levels 8 and 57 rely on.
  - **Never a surprise:** a forecast chip shows projected deliveries against the goal, and a station that would fill later gets a dashed ring and a "full wk N" tag.
  - **Controls:** a "Planning · time frozen" chip while planning. The bottom tray holds the resources (carriages and interchanges are dragged from it), undo/redo for the last 3 edits, restart, Hint, Breather and Run week.
  - **Week flow:** weekly cards (with "View map first"), a Last Call banner with a Breather button, a staged win, and a gentle fail screen offering "Retry from week N".
  - **Tutorial and tips:** levels 1–2 have a Pip coach and a hand with Skip; each of the 15 rules gets a one-time tip the first time it appears. A level left mid-way resumes at the start of that week.
- **Levels, Shop, Settings:**
  - **Levels:** a map of all 120 levels across the 10 cities.
  - **Shop:** Hint and Breather packs for Tokens, free Tokens for an optional video, Remove Ads and Restore purchases.
  - **Settings:** adds colour-blind line patterns, reduce motion and an opt-in daily reminder.
- **Screenshots:** six real scenes in `shots.json` (home, solve, plan, card, win, map), and `store/FACTS.md` has a line for every new system.
- **Art:** the glyph sheet cuts off its edge tokens, so `scripts/art/bake.py` rebuilds all eight as full discs, plus the UI icons and a Token coin, all as bundled PNGs.

**Not done in this stage**
- **Online duels, Daily puzzle, Station Garden and other meta screens:** not built yet. Online multiplayer is part of this game's design, so if stage 3 doesn't cover it, it is still missing.
- **Pinch-zoom and hold-to-pause:** not added. Every week already starts paused, and every level fits on screen. `store/FACTS.md` doesn't claim either.

**For the studio:** in the web preview, Chrome moves the start of a drag near the screen edge, so I drove drags with the mouse instead. Popups also render 500px wide there and look shifted; that is a preview artifact, not a game bug. I noted both in memory.
