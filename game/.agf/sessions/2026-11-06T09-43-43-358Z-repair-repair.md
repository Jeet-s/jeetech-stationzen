**level_replay (L24).** The touch positions the game reported were correct. The cause was the gesture handling.
- **Cause:** on a loaded device, `adb input swipe` sends finger-down, then finger-up at the far station, with no move events in between. The board only reacted to move events, so the drag read as a tap and opened the Kite station's info card instead of drawing the line. The same thing failed levels 1 and 9 on a cold emulator.
- **Fix:** the point where the finger lifts now counts as a final move.
- **Also:**
  - A touch on a station's disc now always means the station, never the line-end knob next to it.
  - The replay now starts new lines on the side of the station away from its knobs.
- **Result:** on the emulator, a replay copying the factory's own loop won levels 24, 1, 9, 2, 3, 36, 60 and 101.

**Factory issues**
1. **Replay swipes:** the replay's 220 ms `input swipe` can arrive with no move events on a loaded machine. Any drag game that only reacts to move events will fail at random. A slower swipe, or one sent as explicit down, move and up events, would make the check reliable.
2. **Level review noise:** the score moves about ±0.2 between runs on the same set, and each run names different levels. Averaging two or three runs before failing would make it stable.
3. **Emulator log folder:** `with-emulator.ts` writes its emulator log to `./logs` under whatever directory it is run from, and fails if that folder doesn't exist. It should use an absolute path.
